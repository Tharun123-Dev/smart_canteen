A modern, digital, and automated canteen solution built using Django, Bootstrap, and JavaScript to simplify menu management, improve ordering speed, and enhance user experience.

✨ 𝘼𝙗𝙤𝙪𝙩 𝙩𝙝𝙚 𝙋𝙧𝙤𝙟𝙚𝙘𝙩
The Smart Canteen System transforms a traditional canteen into a smart, digital platform where:

🧑‍🍳 𝙐𝙨𝙚𝙧𝙨 𝘾𝙖𝙣:
📲 View live digital menu
🛒 Select items & add to cart
💸 Place orders seamlessly
🔄 Track order status (Pending → Preparing → Ready)
⭐ Rate food items

🛠️ 𝘼𝙙𝙢𝙞𝙣 𝘾𝙖𝙣:
➕ Add/Edit/Delete menu items
📦 Control stock availability
📈 View daily/weekly sales reports
🧾 Monitor live orders
👤 Manage users & permissions
✔ Designed for colleges, hostels, corporate offices, and smart cafeterias

🌐 Frontend
Technology	Purpose
HTML5	Base structure
CSS3	Styling & layout
Bootstrap 5	UI components & responsiveness
JavaScript (ES6)	Dynamic interactions, fetch calls

🖥️ Backend
Technology	Purpose
Django 4.x	MVC framework, routing, ORM
Django REST Framework (Optional)	API development
SQLite / MySQL	Data persistence

⚙️ Tools Used
🔧 VS Code
🌐 Postman for API testing
🗂️ GitHub for version control
🧪 Django Admin for instant dashboard
